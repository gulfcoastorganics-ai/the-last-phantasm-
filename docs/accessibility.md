# Combat Accessibility

Mouse and touch select Canvas tiles; DOM buttons expose every command and facing. Keyboard uses H/J/K/L for the tile cursor, Enter to confirm, Escape to cancel, M for Move, R for Attack, E to end turn, I to inspect, arrows/WASD to pan, and F to focus.

Live announcements cover ready units, commands, movement, attacks, damage, misses, defeat, and battle results without announcing pointer hover. Controls use semantic buttons, visible focus, 2.6rem minimum targets, responsive layout, high-contrast-compatible colors, optional audio, a screen-shake setting, and reduced-motion movement/camera behavior.
