# Local Setup

Requirements: a current Node.js LTS release and npm.

```bash
npm install
npm run dev
```

Vite prints the local URL. Keyboard controls are WASD or arrows to pan, `F` to recenter, and backquote to toggle diagnostics. Drag with mouse or touch to pan and use the wheel or visible buttons to zoom.

Run the complete local gate with `npm run check`. Generated `dist/` output is not committed.
